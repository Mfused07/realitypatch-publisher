Privacy Policy

Last updated: 31 October 2026

RealityPatch Publisher ("the tool") is a private publishing tool used only by the owner of the Reality Patch channel.

What data the tool uses

  • The TikTok access token and refresh token issued when the channel owner signs in with TikTok.
  • Basic profile information of the owner's own account (display name, avatar, open id) to show which account is signed in.
  • The owner's own videos and captions that are uploaded.

How it is stored

Tokens are stored only on the owner's own computer, in a private file that is never shared or published. No data is sold, shared with third parties, or used for advertising.

Other users

The tool does not collect, read or store any data about other TikTok users or viewers.

Deleting data

The owner can revoke access at any time in TikTok's settings (Security and permissions, Apps), which ends the tool's access; the local token file is then deleted.
